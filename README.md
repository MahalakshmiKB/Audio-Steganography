Audio Steganography Using LSB Technique

About the Project
Audio Steganography is a Python-based application that enables users to securely hide secret messages within audio files using the Least Significant Bit (LSB) technique.

The project focuses on secure communication by embedding confidential information into audio signals while maintaining the audio's perceptual quality.

Features
- Hide secret messages inside audio files.
- Extract hidden messages from audio files.
- User-friendly graphical interface using Tkinter.
- Secure message handling using encryption.
- Audio processing and file management.

Technologies Used
- Python
- Tkinter
- SQLite
- Cryptography (Fernet)
- FFmpeg
- Least Significant Bit (LSB) Technique

How to Run
1. Install Python.
2. Install the required dependencies.
3. Ensure FFmpeg is installed and configured.
4. Run the application:

```bash
python audiosteganography.py
```

Project Purpose
To demonstrate how steganography and encryption techniques can be combined to provide an additional layer of security for digital communication.
